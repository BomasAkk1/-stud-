# GNU/Linux
GNU/Linux - общее определение операционных систем, использующие ядро Linux, готовых для конечной установки на пользовательское оборудывание. Единая система что создает дестрибутивы.

Дистрибутив — это готовый комплект для установки программного обеспечения или операционной системы, который включает ядро, набор файлов, программы и установщик

Основные: Red Hat / Fedora, OpenSUSE, Ubuntu, Debian, Slackware, Gentoo, Arch Linux.
Часто отличаются друг от друга интерфейсом, оставляя внутрянку ту же.


Linux - ядро
Ядро бесполезно само по себе, оно работает как посредник между железом и программой.

GNU - оперативка
Оперативная система нужна для управления аппаратным обеспечением компьютера, запуска программ и удобного взаимодействия пользователя с устройством.

inode - структура файлов, нужна для хранения методанных (служебной инфы)
Имена файлов => inode => физ данные
Любой файл в каталоге GNU/Linux имеет имя и номер inode. Методанные можно узнать указав номер.

Индексные дескрипторы в файловых системах предназначены для хранения метаданных о файлах, каталогах и др. объекта

Имена файлов (папок) => inode => физические данные
Любой файл в каталоге GNU/Linux имеет имя и номер inode. Пользователь может узнать метаданные этого файла, указав его номер inode
Inodes  являются уникальными на уровне разделов. Вы можете иметь два файла с одинаковым номером inode, если они находятся в другом разделе
Количество inodes каждой файловой системы определяется при создании файловой системы

Как правило, каждый inode хранит следующие атрибуты:
размер;
владелец;
дата/время;
разрешения и контроль доступа;
расположение на диске;
тип файла;
количество ссылок;
дополнительные метаданные о файле.

# Структура
/ - корень, выше всех и вся

/bin — основные программы и команды для всех пользователей (например, ls, cat)
/boot — файлы, которые нужны для запуска операционной системы (ядро Linux)
/dev — файлы устройств (жесткие диски, клавиатура, мышь)
/etc — настройки программ и всей системы./home — личные папки пользователей
/lib — библиотеки, нужные для работы программ и системы
/media и /mnt — папки для подключения флешек, дисков и других носителей
/opt — дополнительные большие программы, установленные отдельно
/proc — виртуальная папка с данными о работе процессора и памяти
/root — личная папка суперпользователя (администратора)
/sbin — системные команды для администратора
/tmp — временные файлы (очищаются при перезагрузке)
/usr — программы и файлы, используемые обычными пользователями
/var — изменяемые данные (логи, почта, базы данных)
