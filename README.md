# GNU/Linux
GNU/Linux - общее определение операционных систем, использующие ядро Linux, готовых для конечной установки на пользовательское оборудывание. Единая система что создает дестрибутивы.

Дистрибутив — это готовый комплект для установки программного обеспечения или операционной системы, который включает ядро, набор файлов, программы и установщик

Основные: Red Hat / Fedora, OpenSUSE, Ubuntu, Debian, Slackware, Gentoo, Arch Linux.
Часто отличаются друг от друга интерфейсом, оставляя внутрянку ту же.


Linux - ядро
Ядро бесполезно само по себе, оно работает как посредник между железом и программой.

GNU - оперативка
Оперативная система нужна для управления аппаратным обеспечением компьютера, запуска программ и удобного взаимодействия пользователя с устройством.


inode - структура файлов, хранящяя методанные (служебную инфу)
